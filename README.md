# tenkei90_liecrew

このリポジトリは、AtCoder「[競プロ典型 90 問](https://atcoder.jp/contests/typical90)」の
liecrew の解を記録・管理するためのものです。

## 使用言語

- メイン: Python
- 追加予定: C++

## 関連リポジトリ

- Python: [smitsu32/abc_liecrew_Python](https://github.com/smitsu32/abc_liecrew_Python)
- C++: [smitsu32/abc_liecrew_cpp](https://github.com/smitsu32/abc_liecrew_cpp)

## 命名規則

- 問題番号（3桁ゼロ埋め）をファイル名とする（例: `001.py`）
- 同一問題番号で複数解法を記録する場合のみ、区別用のsuffixを付与（例: `003_bfs.py`, `003_dfs.py`）
